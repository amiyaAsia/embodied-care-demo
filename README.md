## Published experience

A 55.5-second overview opens on a refusal and shows two contrasting responses to it, an explicit rewind, specific coach feedback, a human review of an unseen case and a difficulty-to-refresher loop. It ends without automatically entering the separately labelled eight-chapter walkthrough. Both sections have independent title cards, progress and playback positions, with a persistent switcher.

The longer story follows care worker Hui Lin through person-centred mealtime practice, a returning encounter, an unfamiliar suspicion check, human review, an after-shift difficulty, a targeted refresher and supervised workplace follow-up. Ms Tan has mild dementia and does not recall the earlier agreement; Hui Lin checks current wishes rather than correcting her memory.

English / 中文, captioned autoplay, pause, restart, chapter navigation and optional Read aloud. No free practice, live AI coaching, real reviewer account or backend. Fictional people and records; no measured physical performance or clinical clearance.

## Publishing contract

The private repository tests and builds a reviewed artifact. A maintainer releases **only** these nine browser assets here:

- `index.html`
- `tour.css`
- `tour-scene.css`
- `tour-app.js`
- `tour-player.js`
- `tour-story.js`
- `overview-story.js`
- `tour-scene.js`
- `assets/amiya-logo.png` — official logo from `amiyaAsia/pitch`

The public workflow checks that each is present and uploads only these files for Pages deployment. Tests and authored application development remain in CareLab. No cross-repository write credential is installed; release transfer is a reviewed maintainer action.

Do not add research data, participant records, internal notes, credentials or private repository contents to this publishing target. Browser-delivered code remains inspectable. Existing public Git history is retained and is not made private by this migration.
