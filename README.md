# Amiya Care Practice — public demonstration

Watch: https://amiyaasia.github.io/embodied-care-demo/

This repository is the **public static publishing target**, not the application development workspace. Canonical source, tests and future application work have migrated to private `amiyaAsia/CareLab`, directory `demo/amiya-care-practice/`.

## Published experience

An eight-chapter authored story follows fictional care worker Hui Lin through person-centred mealtime practice, a returning encounter, an unfamiliar check, human review, an after-shift difficulty, a targeted refresher and supervised workplace follow-up.

English / 中文, captioned autoplay, pause, restart, chapter navigation and optional Read aloud. No free practice, live AI coaching, real reviewer account or backend. Fictional people and records; no measured physical performance or clinical clearance.

## Publishing contract

The private repository tests and builds a reviewed artifact. A maintainer releases **only** these seven browser assets here:

- `index.html`
- `tour.css`
- `tour-scene.css`
- `tour-app.js`
- `tour-player.js`
- `tour-story.js`
- `tour-scene.js`

The public workflow checks that each is present and uploads only these files for Pages deployment. Tests and authored application development remain in CareLab. No cross-repository write credential is installed; release transfer is a reviewed maintainer action.

Do not add research data, participant records, internal notes, credentials or private repository contents to this publishing target. Browser-delivered code remains inspectable. Existing public Git history is retained and is not made private by this migration.
